# Q SPACE 静态体验版

此目录用于通过 GitHub 将已构建的独立体验版导入 REDcowork，不包含正式站后台或账户配置。

这是现有 Q SPACE 的纯前端本地演示。采用标准静态多文件结构：小入口 `index.html` 引用同目录的样式、资源注册表和应用脚本，不需要安装依赖、构建、环境变量、数据库或业务服务器。三个家园、角色、音乐手帐、发现、附歌留言、小响点歌和 K 歌包厢保留原有体验。

此版本从已构建单页机械拆分，没有重新编译、格式化、改写或删减应用代码。入口仅 508 字节，避免平台预览健康检查在截取大型 HTML 响应时提前关闭连接；较大的代码和图片资源由浏览器分别加载。

身份和内容保存在当前浏览器。好友、来访者、聊天回应与邀请是明确标注的本地示例；没有真人联机、QQ 音乐登录、LLM 或实时语音合唱。

## 导入方式

将本目录的全部七个文件下载到同一目录，作为普通静态网站使用，入口为 `index.html`。不要只下载入口。平台是否成功导入、预览和运行，应以目标环境中的实际结果为准。

请对导入助手明确要求：

1. 下载文件时只写入磁盘，不使用 `cat`、read-file 等工具将完整源码或资源文件读入模型上下文，不输出 Base64 或完整源码。
2. 保持全部文件原样，不重新生成、格式化、重构、合并或删减。保留 `./app.css`、`./assets.js`、`./app.js` 相对路径、`#/` 路由和媒体地址，不添加 `<base>`。
3. 保留入口中的脚本顺序：先 `assets.js`，后 `app.js`，均为普通脚本；不要添加 `async`、`defer` 或 `type="module"`。资源注册表的全局绑定由应用脚本直接读取。
4. 只返回文件字节数、SHA-256 与各资源的静态预览 HTTP 状态，之后在浏览器验证页面。若发生故障，只读取相关的短错误信息。
5. 不创建 iframe 或跳转页，不连接正式站业务 API。保留本目录的音乐署名和第三方许可文件。
6. 先提供预览，不自动提交招聘作业。

以 HTTP(S) 静态服务运行；公开交付使用 HTTPS。宿主需要允许同源脚本和样式、内嵌 `data:` 图片及字体、应用的动态样式和下述远程媒体。相对文件路径支持子目录部署，hash 路由不需要服务器重写。直接打开 `file://` 不作为验收方式。

以上做法可减少模型需要读取的源码上下文，但不能保证平台的具体扣费或剩余 Token 消耗。不要把 minified JavaScript 当作需要模型重新理解或重写的提示词。

## 外部媒体

页面通过既有公开静态 URL 加载 **25 首完整音频及 2 个登录背景视频，共 27 个媒体资源**，需要联网。这些地址位于 `qspace.leowi.xyz/music/` 和 `qspace.leowi.xyz/media/login/`；不调用该正式站的业务接口。媒体许可、来源与使用说明见 [MEDIA-LICENSES.md](MEDIA-LICENSES.md)。

公开媒体的可用性可能变化；浏览器可能要求手动点击播放以开启声音。应用还保留一个由用户主动打开的完整在线版本链接。

## 文件范围

本目录发布且仅发布以下七个文件：

- `index.html`：508 字节的静态入口，保持样式及脚本加载顺序。
- `app.css`：从原单页提取的完整样式，所用图片和字体仍为内嵌资源。
- `assets.js`：原始 `QSPACE_ASSETS` 图片资源注册表。
- `app.js`：从原单页提取的完整应用脚本及场景。
- `MEDIA-LICENSES.md`：音乐署名、许可链接与公开媒体说明。
- `THIRD-PARTY-NOTICES.md`：运行依赖及内嵌 Inter 字体许可。
- `README.md`：本说明。

不包含原项目的开发源码目录、构建或检查脚本、音视频文件、账号凭据、服务器代码、环境变量文件或原项目的 Git 历史。运行所必需的前端 JavaScript 保留在上述静态文件中。未为项目自有代码、品牌或图像添加新的开源授权。
