# Q SPACE 静态体验版

此目录用于通过 GitHub 将已构建的独立体验版导入 REDcowork，不包含正式站后台或账户配置。

这是现有 Q SPACE 的纯前端本地演示。`index.html` 已包含完整页面、样式、脚本、场景及所需图片；不需要安装依赖、构建、环境变量、数据库或业务服务器。三个家园、角色、音乐手帐、发现、附歌留言、小响点歌和 K 歌包厢保留原有体验。

身份和内容保存在当前浏览器。好友、来访者、聊天回应与邀请是明确标注的本地示例；没有真人联机、QQ 音乐登录、LLM 或实时语音合唱。

## 导入方式

将本目录作为普通静态网站使用，入口为根目录 `index.html`。只有平台确认支持仓库导入或下载文件到工作区后，才使用相应功能；本目录的准备不代表平台已成功导入。

请对导入助手明确要求：

1. 下载或解压文件时只写入磁盘，不使用 `cat`、read-file 等工具将整个 HTML 读入模型上下文，不输出 Base64 或完整源码。
2. 保持 `index.html` 原样，不重新生成、改写、格式化、重构、拆分或删减。保留内联 script/style/data URI、`#/` 路由和媒体地址。
3. 只返回文件字节数、SHA-256 与静态预览请求的 HTTP 状态，之后在浏览器验证页面。若发生故障，只读取相关的短错误信息。
4. 不创建 iframe 或跳转页，不连接正式站业务 API。保留本目录的音乐署名和第三方许可文件。
5. 先提供预览，不自动提交招聘作业。

以上做法可减少模型需要读取的源码上下文，但不能保证平台的具体扣费或剩余 Token 消耗。不要把 minified JavaScript 当作需要模型重新理解或重写的提示词。
